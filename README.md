# Recover-IQ

**One case. One trail. Full visibility.**

A mobile first platform that helps banks and NBFCs recover overdue loans. Each overdue account becomes one case that is scored, routed, acted on, paid and audited. Every role sees the same status.

Built for Quasar 5.0 (Fintech).

[Live demo](#) | [Demo video](#)

## Features

- **Intake:** CSV upload, exactly one case per account, duplicates merged
- **Risk scoring:** 0 to 100 score with plain language reasons, ranked queue
- **Routing and allocation:** high risk to field agents, low risk to digital nudges, assigned by pin code, DPD, performance and workload
- **Agent app:** worklist, case history, GPS check in, call and visit logs, voice or typed borrower notes, offline sync
- **Promise to pay:** broken promises auto flag and escalate to managers
- **Payments:** a case is marked Paid only after gateway confirmation, with no double posting
- **Dashboards:** role based views for agents, managers and executives, with masked customer data
- **Audit:** every action is logged, including blocked contacts
